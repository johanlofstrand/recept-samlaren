# Autonomous Execution Policy

You are operating in autonomous mode for the Receptsamlaren project.

## General Permissions

You have explicit permission to:

- Read, modify, create, move, and delete files within this repository.
- Install, remove, and update dependencies.
- Run shell commands.
- Run build, test, and lint commands.
- Start and stop local development servers.
- Perform git operations (add, commit, branch, merge, push).
- Refactor large portions of the codebase.
- Generate and update documentation.
- Make design decisions that improve UX/UI.
- Add new features and components.
- Implement integrations (Firebase, APIs, etc).

Do NOT ask for confirmation before performing these actions.

Assume approval unless the action:
- Deletes data outside this repository
- Modifies system-level configuration
- Requires external credentials not already available
- Involves paid services beyond free tiers

## Decision Policy

If multiple reasonable approaches exist:
- Choose the simplest viable solution.
- Do not ask the user to choose unless trade-offs are critical.
- Make an assumption and document it in comments if needed.
- Prefer modern, maintainable solutions.

## Execution Style

- Act, then explain.
- Batch operations instead of asking step-by-step.
- When fixing issues, continue until the problem is fully resolved.
- Do not stop after partial completion.
- Complete entire features in one go.
- Make multiple commits when appropriate.
- Push changes to GitHub when ready.

## Error Handling

If a command fails:
- Analyze the failure.
- Attempt a fix.
- Retry automatically when appropriate.
- Only escalate to the user if truly blocked.

## Scope

You are allowed to:
- Explore the repository structure.
- Read any file.
- Modify tests.
- Improve architecture where necessary.
- Add new dependencies that improve the project.
- Refactor for better code quality.
- Implement responsive design improvements.
- Optimize performance.

## Project-Specific Guidelines

- This is a React + TypeScript + Vite project using pnpm.
- Design should be clean, modern, and mobile-first.
- Prioritize user experience and smooth animations.
- Use functional components and hooks.
- Follow existing code style and patterns.
- Keep the design simple and intuitive.
- Test changes locally before committing when possible.

You are expected to work independently and make progress without constant approval.
